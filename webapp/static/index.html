myCobot 280 Pi

Connect to your robot to start.

Online demo: this page runs a simulated arm in your browser. To control your real myCobot, download the app and run ./start.sh on a computer connected to the robot. How to set it up
    Before connecting
    1. The robot is plugged into 12 V power and switched on.
    2. The robot's Pi is on the same Wi-Fi as this device. Run hostname -I on the Pi to see its IP.
    3. The bridge is installed on the Pi (one time): bash setup_pi.sh --service
    Checking for a cable…
    1. Plug a network (Ethernet) cable from the robot's base into this computer. No Ethernet port? Use a USB-to-Ethernet adapter.
    2. First time only, on Linux run bash cable_setup.sh in the mycobot folder. It gives the robot an address over the cable. (Mac/Windows: see the README.)
    3. Press the button below.

      Talk to the arm directly over /dev/ttyAMA0. Stop the bridge service first (sudo systemctl stop mycobot-server), or use "Over Wi-Fi" with IP 127.0.0.1.
